Privacy Policy & Data Security

Last updated: September 24, 2026. This Privacy Policy details the data handling, storage practices, and network communications of the TikTok CLI executable and documentation website.

1. Zero Telemetry & Local Execution

The TikTok CLI binary contains zero tracking code, zero analytics SDKs, and zero telemetry beacons. Developer and autonomous agent workflows must remain completely private. The tool does not collect usage metrics, IP addresses, execution timestamps, or target URLs/queries back to any SpaceCorps server. The only network requests made by the tool are outbound HTTPS requests made directly to the Apify API endpoint (https://api.apify.com/v2/ or your custom TIKTOK_API_URL) to fulfill user-initiated scrape operations.

2. Cryptographic Credential Protection

Authentication tokens and API keys are sensitive secrets. TikTok CLI strictly refuses to save secret tokens in plain-text configuration files by default. Instead, API tokens are delegated directly to the secure credential store provided by the host operating system: macOS Keychain Services via the native security subsystem, Windows Data Protection API (DPAPI) encrypted under user-specific credentials, or the freedesktop.org Secret Service daemon via libsecret on Linux.

3. Local Configuration Metadata

Non-sensitive configuration metadata—specifically account alias names and identity labels—is stored locally in an owner-restricted YAML file (chmod 0600 on POSIX platforms) located within your standard system configuration directory (~/Library/Application Support/tiktok-cli on macOS, ~/.config/tiktok-cli on Linux, or %APPDATA%\tiktok-cli on Windows). This file can be inspected, backed up, or deleted at any time.

4. Website Privacy

This documentation website is hosted as a static site on GitHub Pages. It contains no tracking scripts, no third-party cookies, and no personal data collection mechanisms. Standard web server access logs are handled directly by GitHub in accordance with GitHub's standard Privacy Statement.
